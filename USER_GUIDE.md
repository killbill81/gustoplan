# 📖 Guide d'Utilisation de GustoPlan

Bienvenue sur **GustoPlan**, votre assistant personnel pour planifier vos repas, gérer vos courses et découvrir de nouvelles recettes. Ce guide vous explique comment utiliser toutes les fonctionnalités de l'application.

## 🚀 1. Démarrage et Navigation

Une fois connecté, vous arrivez sur l'écran principal. La barre de navigation (en haut sur ordinateur, en bas sur mobile) vous permet d'accéder aux différentes sections :

*   🏠 **Mon Menu** : Votre planning de la semaine.
*   🛒 **Faire les courses** : Votre liste de courses interactive.
*   📅 **Mes Plans** : Gérer vos différents plannings sauvegardés.
*   🍳 **Mes Recettes** : Votre carnet de recettes personnel.
*   🥕 **Mes Ingrédients** : Base de données de produits.
*   👥 **Amis & Partage** : Fonctions sociales.

---

## 📅 2. Planification des Repas (Mon Menu)

C'est le cœur de l'application. Ici, vous organisez vos repas pour la semaine.

### Gérer les Plans
*   **Sélecteur de Plan** : En haut, choisissez le plan sur lequel vous travaillez (ex: "Semaine Type", "Vacances").
*   **Créer un Plan** : Cliquez sur le bouton `+` à côté du sélecteur pour créer un nouveau planning vierge.
*   **Actions** : Utilisez les icônes pour **Renommer** ✏️, voir l'**Historique** 🕒 ou **Supprimer** 🗑️ le plan actuel.

### Remplir le Planning
*   **Navigation** : Utilisez les flèches "Préc." et "Suiv." pour changer de semaine.
*   **Ajout Rapide** : Cliquez sur le bouton **IA Semaine** 🤖 pour laisser l'intelligence artificielle suggérer des repas pour toute la semaine.
*   **Outils** :
    *   **Vider le menu** : Efface tout le contenu de la semaine visible.
    *   **Exporter (PDF)** : Télécharge une version imprimable de votre menu.

---

## 🛒 3. Faire les Courses

GustoPlan génère automatiquement votre liste de courses en fonction des recettes placées dans votre planning.

### Fonctionnement de la Liste
*   **Catégories** : Les articles sont triés par rayon (Fruits & Légumes, Épicerie, etc.) pour vous faire gagner du temps en magasin.
*   **Cocher des articles** : Cliquez sur un article ou sa case à cocher. Il se déplace automatiquement en bas dans la section "Articles cochés" et se grise.
*   **Ajout Manuel** : Une barre de recherche en bas vous permet d'ajouter des produits qui ne sont pas dans vos recettes (ex: "Liquide vaisselle").

### La Corbeille 🗑️
Si vous supprimez des articles (en cliquant sur la petite croix), ils vont dans la corbeille.
*   Cliquez sur l'icône **Corbeille** en haut à droite pour voir les articles supprimés.
*   Vous pouvez les **Restaurer** (flèche arrière) ou les **Supprimer définitivement**.
*   *Note : La corbeille est spécifique à chaque Plan. Si vous changez de plan, la corbeille s'adapte.*

---

## 🍳 4. Mes Recettes

Créez votre propre livre de cuisine numérique.

*   **Ajouter** : Cliquez sur "Ajouter une recette".
*   **Détails** : Renseignez le nom, les ingrédients, les étapes, le temps de préparation et le nombre de personnes.
*   **Calcul Automatique** : Lorsque vous ajoutez cette recette au planning, GustoPlan recalcule automatiquement les quantités d'ingrédients dans la liste de courses selon le nombre d'invités !

---

## 🥕 5. Mes Ingrédients

Gérez une base de données d'ingrédients pour faciliter la création de recettes. Vous pouvez définir l'unité par défaut (kg, litres, pièces) et la catégorie de chaque produit.

---

## 🤝 6. Fonctions Sociales

Cuisiner, c'est mieux à plusieurs !

*   **Amis** : Recherchez des utilisateurs par leur pseudo ou email pour les ajouter à votre liste d'amis.
*   **Partage** :
    *   **Envoyer une copie** : Votre ami reçoit une copie de votre plan qu'il peut modifier sans affecter le vôtre.
    *   **Collaboration** : Invitez un ami à modifier le **même** plan que vous en temps réel (idéal pour les couples ou colocataires).

---

## ⚙️ 7. Paramètres

Accessible via votre profil (icône utilisateur) :
*   **Mode Sombre 🌙** : Basculez l'interface en thème sombre pour moins de fatigue visuelle.
